# HTML 詩語辞典 — 素のHTMLで詩をつくるための辞書

CSSもJavaScriptも使わず、**素のHTMLだけ**で詩的な作品をつくる。
そのための発想を助ける、HTML5 のタグと機能のビューア（辞書）です。

単なる一覧ではありません。**めくり・しおり・掛け合わせる**ための仕掛けがあります。

## つかいかた

`index.html` をブラウザで開くだけ。ビルドも、依存も、ネット接続も不要です。

```
open index.html        # macOS
xdg-open index.html    # Linux
```

## 4つのモード

| モード | できること |
|--------|-----------|
| **めくる** | 標本を1枚ずつ。スワイプ／`←` `→`／**ランダム**(`R`)で、偶然に出会う。 |
| **一覧** | すべてを俯瞰。言葉で検索、種類で絞り込み。 |
| **しおり** | 気になった標本を ☆ で挟み、あとで見返す。 |
| **掛け合わせ** | 複数を選んで組み合わせ、「問い」を立ち上げる。「**種をまく**」で偶然に任せることも。 |

各標本（タグ）には、次の4つが添えられています。

- **詩の素材として** — その要素の、詩にとっての面白さ
- **けしかけ** — そこから詩を芽吹かせるための、具体的なそそのかし
- **見本** — 実際にブラウザで描画される、生きた標本（すべて素のHTML）
- **補足** — 技術的なヒント（任意）

「しおり」と「掛け合わせ」の選択は、ブラウザの localStorage に保存されます。

## 「作品」と「ツール」の線引き

- つくる**作品** = CSSもJSも使わない、素のHTMLだけ。
- 発想を助ける**このツール自体** = ランダム・しおりの保存・掛け合わせ作業場のために、CSS/JS を使っています。

## 純HTMLの作例（到達点）

`examples/` に、CSSもJSも一切使わない素のHTMLだけの小品を置いています。
ソースを開いて、どのタグでできているか確かめてみてください。

- `details-confession.html` — `<details>` で、開くまで届かない告白
- `alt-unseen.html` — `<img alt>` だけに書かれた、見えない絵
- `ruby-double.html` — `<ruby>` で、表記と読みをずらす二重の声
- `eternal-morning.html` — `<meta refresh>` で巡る、終わらない朝のループ詩

## ファイル構成

```
index.html      アプリの骨格
style.css       辞書の装い（ツール用）
app.js          めくり・しおり・掛け合わせの仕掛け（ツール用）
data.js         HTML5 タグ/機能の辞書データ + 詩の方位 + 題材
examples/       純HTMLの作例（作品。CSS/JSなし）
```

## データを足す

`data.js` の `ELEMENTS` に、同じ形のオブジェクトを追加するだけで標本が増えます。
`STRATEGIES`（詩の方位）と `THEMES`（題材）も、自由に書き加えてください。
